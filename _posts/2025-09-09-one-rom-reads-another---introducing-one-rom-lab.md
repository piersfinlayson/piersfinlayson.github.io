You can now use One ROM, the most flexible retro ROM replacement, as a ROM reader.  Pair it with Airfrog and you can read ROMs wirelessly.  

One ROM Lab is a new firmware for One ROM that turns the stock hardware into a ROM reader, reading both original ROMs and ROM replacements.  

Airfrog is a tiny wireless co-processor for ARM microcontrollers which I use here to add a wireless GUI onto One ROM Lab.  

As well as adding One ROM Lab functionality, the Airfrog firmware now includes a generic bi-directional channel implemenation, airfrog-rpc, which allows SWD controllers and targets to safely communicate using the target's SRAM.
